Phone

The app

One Flutter codebase builds both apps.

Flutter Dart 3

The whole app: game board, start screen, history, leaderboard, admin screens.

Provider provider

App state: puzzle library, records, scores, sign-in.

Catalyst Flutter SDK zcatalyst_sdk

Connects the app to the Zoho Catalyst project.

HTTP http

Calls to the Catalyst functions for puzzles, scores and uploads.

Local storage shared_preferences · path_provider

Keeps progress, streaks and downloaded cartoons on the phone.

Image image

Draws the word page, finds the caption, shrinks uploads, builds the share card.

Shake to reshuffle sensors_plus

Reads the phone's motion so a shake re-scrambles the words.

Sounds audioplayers

Taps, correct-word and win sounds.

Push notifications firebase_messaging · flutter_local_notifications

New-puzzle alerts and local reminders.

Share card share_plus · qr

Shares the win picture with a QR code to download the app.

No screenshots in game no_screenshot

Blocks screenshots while a puzzle is open.

Admin pictures image_picker

Picks the cartoon and wordless cartoon when an admin adds or edits a puzzle.

Updates package_info_plus · crypto

Checks the app version and verifies the Android update file (SHA-256) before installing.

Dates intl

Day names, times and the 9 AM / 3 PM / 9 PM slots.

Cloud

Zoho Catalyst back end

Node.js 20 serverless functions, Development environment.

FunctionTypeWhat it does
jumble_dataAdvanced I/OThe main API: puzzles, uploads, editing, scores, leaderboard, pictures, the admin web page (upload and player leaderboard) and the notification timer.
jumble_authAdvanced I/OSign-in: email and password, plus Google and Zoho sign-in for the admin page.
blujem_dailyAdvanced I/ODaily puzzle pipeline and the Android app-update file and notes.
blujem_daily_jobJobThe slow part of the pipeline: asks the Zia agent to read a puzzle and checks the result.
jumble_aiAdvanced I/OAI helpers for building puzzles.
jumble_layoutJobAsks the Zia layout agent where the words and boxes sit on an old full puzzle sheet.

Data Store ZCQL

Tables for Users and Puzzles: words, answers, slot, publish time.

Stratus bucket: blujem

Cartoon and wordless cartoon pictures, plus the Android update file and its notes.

Cron (Job Scheduling) 6 · 9 · 15 · 21 IST

Opens each puzzle on time and sends the push notification.

Authentication hosted login

Google and Zoho sign-in for admins on the admin page.

Zia AI agents

Read puzzle images and find where the words and boxes are.

Cache

Holds slow job results until the app collects them.

Environment variables

Secrets kept out of the code: token key, cron key, Firebase key.

Shipping

How players get new versions

iOS · TestFlight

Built with Xcode, uploaded to App Store Connect, testers install from TestFlight.

Android · in-app update

Signed APK built with Gradle, stored in Stratus; the app offers it, checks it, then installs.

Tests

Flutter tests for the app, Node's built-in test runner for the server.

Catalyst CLI

catalyst deploy sends the functions to the cloud.
